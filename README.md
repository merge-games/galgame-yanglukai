# 璐恺十二钗

一部**搞笑校园视觉小说（galgame）**：主角是同学杨璐恺的 12 张表情照，每一张对应一位"钗"——同一个人被切成十二种人格（皮肤）。她们从开学第一天一路陪你到毕业照，争宠、整活、各有一条自己的小支线；你负责取名字、做选择、刷好感，最后按好感结算结局。

* 单文件网页：`index.html`（HTML + CSS + 原生 JS，**零依赖、无构建、无 CDN、无外部字体、无音频文件**）
* 双击 `index.html` 即可离线运行（`file://` 下也能存档）
* 移动端、桌面端均可玩
* 基调：纯搞笑、干净、适合发同学群。"后宫"只是玩梗，全篇没有任何露骨内容

> 谨以此，纪念那些被我们笑过、也被我们记住的大学时光。

### 2.4 好感度与 15 个结局判定

* 开局所有人好感 = **1**（序章你和十二钗都打过招呼了）。
* 每次选择给**指定几位钗加好感**（`aff`，通常 +1~+4），或给**全部 12 位一起加**（`affAll:+2`）。
* 单角色好感上限显示值 `AFF_MAX = 18`（心形与进度条按 18 归一化）。
* 结算规则（`computeEnding()`，按顺序判定）：

| 顺序 | 条件 | 结局 |
| --- | --- | --- |
| 1 | 12 位好感**全部 ≥ 14**（`HAREM_THRESHOLD`） | 《十二钗齐聚》（隐藏） |
| 2 | 「一个人待着」选项累计 **≥ 5** 次（`flags.alone`） | 《毕业快乐》 |
| 3 | 「装死 / 回避」选项累计 **≥ 5** 次（`flags.dodge`） | 《路人结局》 |
| 4 | 12 位好感**全部 ≤ 4**（兜底） | 《路人结局》 |
| 5 | 其余 | **好感最高那位钗**的专属结局（并列时按"最后一次涨好感的先后"决胜） |

* 12 个专属结局 + 3 个特殊结局 = **15 个**，图鉴条目数与「结局收集 X / N」会跟着 `ENDINGS.length` 自动变。

## 三、怎么改台词 / 加分支

打开 `index.html`，找到 `/* 3. 剧本数据 */` 下面的 `var SCRIPT = [ ... ]`，全部内容都是**数据**，改字不用碰引擎。

### 3.1 一个节点长这样

```js
{ id:'p03', who:-1, bg:'gate', place:'校门口 · 早上七点四十', text:'九月一号，早上七点四十。校门口的行李箱轮子碾过地砖，声音像一场小型阅兵。' },
```

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `id` | ✅ | 节点唯一 id（字符串），选项/`cond`/`next` 靠它跳转 |
| `who` | ✅ | 说话者：`0`~`11` 对应十二钗；`-1` 表示**旁白**（自动套旁白样式） |
| `text` | ✅ | 台词正文，可用 `{name}` 占位玩家名字 |
| `bg` | ❌ | 场景 id（见 2.6 表格）。省略则沿用上一句的场景 |
| `place` | ❌ | 顶栏「地点 · 时间」标签。省略则沿用 `bg` 的默认标签 |
| `chapter` | ❌ | `true` 时按"章节标题"样式居中放大显示（本作用在幕标题上） |
| `next` | ❌ | 下一句的 id。**省略时自动播放下一个数组元素**；写 `'@end'` 表示进入结局结算 |
| `cond` | ❌ | 按剧情标记分流，见 3.3 |
| `choices` | ❌ | 选项数组，见 3.2 |

### 3.2 选项长这样

```js
{ id:'a2Choice', who:0, text:'你要选谁当同桌？', choices:[
  { label:'跟拼好恺坐——左边放书，右边放他', aff:{5:3, 4:1}, next:'a2A1' },
  { label:'把课桌拼成一个圈，让十二钗轮流来坐同桌', affAll:2, next:'a2C1' },
  { label:'自己坐最后一排靠窗，安静一点（一个人待着）', flags:{alone:1}, next:'a2D1' }
]},
```

* `label`：按钮文字（建议 ≤ 22 个汉字，窄屏会自动换行），同样支持 `{name}`。
* `aff`：`{钗下标: 加多少}`。下标就是 2.5 表的 `#-1`，例如 `{5:3}` = 拼好恺 +3。
* `affAll`：给全部 12 位一起加（用来做"雨露均沾 → 十二钗齐聚"路线）。
* `flags`：**数值**表示累加计数（`alone` 独处、`dodge` 回避，用于两个新结局），**字符串**表示打标记（`club`/`event`/`wish`，用于 `cond` 分流）。
* `next`：选完跳去哪个节点 id。

### 3.3 按选择结果改后续台词（重要分支）

```js
{ id:'a1R', who:0, text:'幼年恺把报名表收好，低头看了你那一栏一眼。', cond:[
  { flag:'club', is:'photo', next:'a1Rp' },
  { flag:'club', is:'drama', next:'a1Rd' },
  { flag:'club', is:'vol',   next:'a1Rv' }
], next:'a1Rn' },
```

命中 `flags[flag] === is` 就跳到对应节点；都不命中则走 `next`。这样"选完之后该幕的后续台词明显不同"——
本作有 3 组重要分支（社团招新 / 校运会项目 / 跨年许愿），每组的后续剧情各有 5~9 个**独有节点**，
并且在同一幕或紧随其后的场景里再用 `cond` 回响一次（`a1R`、`a59`、`b37`、`c13` 四个分流节点，共 16 条两两不同的台词）。

### 3.4 加一条新分支的步骤

1. 在 `SCRIPT` 里给新节点起 id（例如 `a1E1`、`a1E2`），把节点写在你希望的**物理位置**（顺序播放是按数组顺序来的）。
2. 在新分支的**最后一句**上写 `next:'xxxx'`，指回主线（否则会顺延到下一个数组元素）。
3. 在对应 `choices` 里加一个按钮，`next` 指向新分支的第一句。
4. 记得给按钮写 `aff` / `affAll` / `flags`。
5. 改完跑一次 `__audit()`，确认 `dupIds` / `dangling` / `unreachable` 三个数组都是空的。

### 3.5 加一个新结局

在 `var ENDINGS = [ ... ]` 里加一项：

```js
{ id:'kai13', who:-1, name:'《结局名》', text:'结局正文，\n 用 \\n 换行，可以用 {name}。' },
```

* `who` 是结局页右上角展示的头像下标（`-1` 表示不显示头像）。
* 再把 `computeEnding()` 里的判定顺序改一改即可（比如加一条"某两位钗都 > 6 触发三角结局"）。
* 图鉴条目数、`结局收集 X / N` 会自动跟着 `ENDINGS.length` 变，不用改文案。

### 3.6 加一种新背景

1. 在 `var BGDECO = { ... }` 里加一段内联 SVG 字符串（`viewBox="0 0 400 600"` + `preserveAspectRatio="xMidYMid slice"`）。
2. 在 `var BGS = { 你的id:{ cls:'bg-你的id', label:'地点 · 时间', deco:BGDECO.你的id } }` 里登记（夜场景加 `dark:true`）。
3. 在 CSS 里加 `.bg-你的id{background:linear-gradient(...)}`，想要专属照片滤镜再加一条 `.bg-你的id img{opacity:…;filter:…}`。
4. 在剧本节点上用 `bg:'你的id'` 引用。

## 五、技术要点

* **单文件零依赖**：整份 HTML 里只有一个 `<script>` 标签、一个 `<style>` 标签，没有任何 `http(s)://` 外链、没有 `@import`、没有 `<link>`、没有字体文件、没有音频文件；图片只有本目录 `assets/` 下的 12 张立绘 + 1 张校园照。
* **取名与 `{name}` 模板**：开局先到取名页，`tpl()` 会把台词、选项标签、结局正文里的 `{name}` 全部替换成玩家名字；空输入/全空格/超过 8 字都会兜底成"同学"或截断。
* **打字机**：`setTimeout` 逐字（26ms/字），点击/空格时若正在打字则**先补全整句**；隔一个字触发一次 WebAudio 短音（节流，不吵）。
* **旁白专属样式**：`who:-1` 的句子自动加 `narr-text`（淡色斜体 + 引号）与 `narr-mode`（对话框左侧竖线 + 淡底），立绘位置改为 12 张缩略图拼成的"群像卡"，顶栏名牌用灰色调。
* **背景**：15 种场景各自一条 CSS 渐变 + `campus.jpg` 的专属透明度/滤镜（`opacity` 0.10~0.20、`sepia/grayscale/saturate` 各不相同）+ 一段内联 SVG 场景元素（`bgDeco.innerHTML`）；两个夜场景另有 `dark` 遮罩。截图实测两两差异最小 4.01，全部不同。
* **立绘**：`assets/kai_XX.jpg`（512×512），圆角卡片 + 白色描边 + 柔和红色光晕，切换时用 `popIn` 关键帧做轻微弹跳入场（先移除 class、强制回流、再加回来，保证动画重播）。
* **音效**：全部用 WebAudio 现场合成（`OscillatorNode` + `GainNode` 包络），共 6 类——旁白逐字音（更低更轻）、角色逐字音、点击音、选择音（双音）、存档音、结局音（7 音小旋律）。静音开关会记住在存档里。
* **条件分支**：`nextIdOf()` 先看 `cond`（按 `flags` 分流），再看 `next`，最后顺序取数组下一项——所有 `next`/`cond`/选项引用都经过悬空检查。
* **响应式**：`viewport-fit=cover` + `env(safe-area-inset-*)` 适配刘海屏；字号用 `clamp()` 自适应；桌面端内容区最大 760px 居中。实测 320 / 360 / 390 / 414 / 500 / 768 六种宽度均无横向溢出，选项按钮最小高度 49px。
* **存档**：`localStorage`，**每推进一句自动存**；存档结构里带 `name` / `flags` / `savedAt`。无效节点安全回退标题页，坏 JSON 静默降级为"无存档"，`localStorage` 被禁用（隐私模式）时 `try/catch` 不报错。
* **结局结算**：`computeEnding()` 按 2.4 的 5 条规则顺序判定，并列时按"最后涨好感顺序"决胜。
* **无 `requestAnimationFrame` 依赖**：全部动画交给 CSS + `setTimeout`，因此在 `--virtual-time-budget` 的无头 Chrome 里也能正常跑测试。

### 5.1 测试钩子（不影响正常玩法）

```js
window.__state()
// => { scene, who, whoIndex, text, fullText, typing, aff:[…12], choices:[…], choiceMeta:[…],
//      ended, ending, endingName, savedAt, screen, muted, unlocked, bg, name, flags, visited, total }
//   scene   : 当前节点 id（如 'p01'）
//   who     : 当前说话者名字（字符串，旁白为 '旁白'）；whoIndex 是对应的 0~11 / -1
//   text    : 当前已显示的文本；fullText 是整句；typing 表示是否正在逐字
//   choices : 当前选项的按钮文字数组（没有选项时为 []）
//   name    : 玩家名字；flags 是剧情标记（alone/dodge/club/event/wish）
//   visited : 本次游戏走过的节点 id 序列（用于分支对比）

window.__goto(sceneId)     // 跳到任意节点（用于调试/测试；节点不存在返回 false）
window.__choose(i)         // 选中第 i 个选项（0 开始），会真的改好感度并跳转
window.__skip()            // 若正在打字 → 补全整句并返回 true；否则推进到下一句
                           // 在取名页调用 = 用当前输入（或默认"同学"）开始游戏
window.__auto(true/false)  // 开关快进（自动播放）
window.__save()            // 手动存档，返回 savedAt 时间戳
window.__affAll(n)         // 调试用：把 12 位好感全部设为 n

window.__setName('阿宝')    // 往取名输入框里填名字（不提交）
window.__name()            // 当前玩家名字
window.__start('阿宝')      // 直接用指定名字开一局新游戏（跳过取名页）
window.__history()         // 本局走过的节点 id 数组
window.__flags()           // 当前剧情标记
window.__audit()           // 剧本自检：{ nodes, textNodes, narrCount, whoCounts[12], choiceNodes,
                           //   choiceOptions, condNodes, dupIds, dangling, unreachable,
                           //   bgs, bgsUsed, bgsUnused, ends, thresholds }
```

> `__skip()` 的语义：**在打字中调用 = 跳过打字机（补全整句）；不在打字中调用 = 推进一句**。
> 所以从一句的开头连续调用两次 `__skip()` 才会跨过该句（第一次补全、第二次推进）。写自动化脚本时按这个节奏循环即可。
> 另外：点「开始新游戏」后先落在**取名页**，老式脚本（点 `btnStart` 后一直 `__skip()`）也能跑通——第一次 `__skip()` 就等于确认名字。

### 5.2 用无头 Chrome 自测（开发时用）

本作全部动画都用 CSS + `setTimeout`（没有 `requestAnimationFrame` 依赖），所以在 `--virtual-time-budget` 下也能跑完整流程。
关键点：**强制 `document.hidden = false`、把 `requestAnimationFrame` 垫成 `setTimeout` 的 shim，必须插在游戏 `<script>` 之前**才生效。

```html
<!-- 注入到 <title> 之前 -->
<script>
Object.defineProperty(document,'hidden',{get:function(){return false;}});
window.requestAnimationFrame=function(cb){return setTimeout(cb,16);};
window.__errs=[];
window.onerror=function(m,s,l,c){window.__errs.push(m+'@'+l);};
</script>

<!-- 注入到 </body> 之前 -->
<pre id="probe"></pre>
<script>
(function(){
  document.getElementById('btnStart').click();
  var g=0; while(!window.__state().ended && g++<2000){
    var s=window.__state();
    if(s.choices.length) window.__choose(0); else window.__skip();
  }
  document.getElementById('probe').textContent =
    'PROBE_JSON_START'+JSON.stringify({st:window.__state(), errs:window.__errs})+'PROBE_JSON_END';
})();
</script>
```

```bash
chrome --headless=new --disable-gpu --virtual-time-budget=20000 --window-size=500,900 \
       --dump-dom "file:///…/杨璐恺十二钗/_probe.html" > out.html
# 再用正则从 out.html 里取 <pre id="probe"> 的内容
```

注意事项：
* `file://` 下 `canvas.getImageData` 会被跨源污染 —— 要验证"截图非空白"请用 `--screenshot=out.png` + Pillow 统计（标准差 / 非白像素比例），不要读 canvas 像素。
* 无头 Chrome 在 Windows 上会把窗口宽度夹到约 500px，想量 360/390 这种真窄屏，可以用 `srcdoc` iframe 把整页塞进去再 `contentDocument` 里量。
* `--dump-dom` 抓出来的中文在 Windows 控制台可能乱码，属终端编码问题，写入文件按 UTF-8 读就正常。
